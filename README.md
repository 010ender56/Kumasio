# Kumasio
Open-source, free, and comprehensive study app.

## Features
  - Simple import
  - In-depth practice quizzes
  - Multiple flashcard study modes: **Review**, **Cram**, and **Spaced-Repetition**.

## Why Use Kumasio?
  - **Free**: We will never include ads or paywall features.
  - **Open-source**: All code is available for anyone to view and modify.
  - **Comprehensive**: Features include flashcards, practice quizzes, and study schedules.
  - **Simple import**: No complicated setup required.
  - **User-friendly**: Features an easy to use and modern, responsive interface.
  - **Truly cross-platform**: Support for Linux, Windows, MacOS, and mobile platforms, using [Tauri](https://v2.tauri.app/).

## Installation
Kumasio is currently *in-dev*. If you truly wish to test out the incomplete software, you can clone the repository and run it locally.

```bash
git clone https://github.com/010ender56/kumasio.git
cd kumasio
npm install
```
